# RGB Foundry · VS Code Themes

A curated collection of handcrafted Visual Studio Code themes.

## Themes

| Theme | Description |
|--------|-------------|
| [Hypnotic Copper](themes/hypnotic-copper/) | Copper-inspired Metal, Glow, and Dark themes with broad workbench coverage and Python, C++, and Markdown previews. |

## Philosophy

RGB Foundry themes emphasize:

- Comfortable long coding sessions
- Carefully balanced contrast
- Semantic consistency
- Minimal visual noise

## Development

Each theme lives in its own directory under `themes/`.
